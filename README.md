# Bleu Blanc Rire

Fan-made, bilingual satirical column about the Montréal Canadiens, written nightly by Claude as the fictional columnist Gaston "Grumpy" Ronchon. Published with GitHub Pages (Jekyll).

- New columns go in `_posts/YYYY-MM-DD-slug.md` with front matter `layout: post`, `title: "English title / Titre français"`, `matchup`.
- Not affiliated with the Club de hockey Canadien or the NHL.
